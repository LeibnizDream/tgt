# Contributing to TGT
Thank you for considering contributing to this project! We welcome contributions from everyone.

## How to Contribute
Please follow these general guidelines:

- Fork the repository and create a feature branch for your changes.
- Keep pull requests focused on a single change whenever possible.
- Follow the existing coding style and project structure.
- Update the documentation when making changes to the code.
- Provide a clear description of your changes in the pull request.

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue with:

- a clear description of the problem or proposal,
- steps to reproduce the issue (if applicable),
- information about your environment, and
- any relevant logs or screenshots.

## Project Maintenance

This repository is made publicly available to support transparency, reproducibility, and community collaboration.

The institute and its employees do not serve as maintainers of this software. The software is provided on a best-effort basis, and there is no guarantee of support, bug fixes, feature development, or review and acceptance of pull requests.

Contributions may be reviewed and merged at the discretion of the repository owner and only as time and resources permit.
